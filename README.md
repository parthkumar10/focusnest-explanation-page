# 🎯 FocusNest

FocusNest is a modern landing page for a fictional productivity product designed to help college students complete distraction-free focus sessions.

The project focuses on **clear communication, visual hierarchy, responsive design, and user flow** rather than complex application functionality.

## 🚀 Live Demo

**[Open FocusNest](https://about-focusnest.pages.dev)**

## ✨ Features

- 🎯 Clear product-focused hero section
- 🧠 Explains the problem and value proposition
- ⚙️ How It Works section
- ⭐ Product features and benefits
- 💬 Social proof section
- 💰 Pricing section
- 🚀 Clear "Start Focusing" calls to action
- 📱 Responsive design for different screen sizes
- ✨ Modern landing-page UI

## 🎨 Project Goal

The goal of this project is to understand how a landing page communicates a product through:

- Structure
- Visual hierarchy
- Copy
- Design direction
- Section organization
- Responsive behaviour
- Iteration

The page is designed around a simple user journey:

**Attention → Value → Understanding → Trust → Action**

## 🛠️ Tech Stack

- **React**
- **JavaScript**
- **HTML**
- **CSS**
- **Cloudflare Pages**

## 📌 Project Scope

FocusNest is intentionally a **landing-page project**.

It does not implement the actual productivity application. The purpose is to explain the product concept and guide visitors toward the primary action: **Start Focusing**.

## 🌐 Deployment

The website is deployed using **Cloudflare Pages**.
